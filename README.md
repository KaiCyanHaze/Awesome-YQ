## 收录说明

本仓库整理 CC98 中与 **yq** 相关的帖子，记录原始标题、版块与原帖链接，方便检索和回看。

- **按原版块分类**：沿用原 README 标注的版块，便于对照查找。
- **按帖子 ID 排序**：各版块内按 ID 从大到小排列，不据此推定发帖时间。
- **按独立帖子计数**：同一帖子在阅读入口中再次出现时，不重复计入收录总数。

点击标题即可前往 CC98 原帖；正文、访问条件及后续编辑以原站为准。

## 参与整理

欢迎补充相关帖子，也欢迎修正标题、版块或失效链接。可以提交 [问题反馈](https://github.com/KaiCyanHaze/Awesome-YQ/issues) 或 [合并请求](https://github.com/KaiCyanHaze/Awesome-YQ/pulls)。

新增条目时：

1. 搜索帖子 ID，确认索引中尚未收录。
2. 找到原帖所属版块，在对应列表中按帖子 ID 从大到小插入。
3. 使用下方格式，保留原标题，并将链接替换为原帖地址。
4. 同步更新顶部帖子数、版块统计与整理日期；新增版块时一并补充导航。

```markdown
- [帖子原标题](https://www.cc98.org/topic/帖子ID)
```

如果暂时无法确认版块，可以先在问题反馈中提供原帖链接和标题。
